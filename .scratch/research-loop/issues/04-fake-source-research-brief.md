# 04 假来源研究简报闭环

**What to build:** 研究任务能够通过可注入的假来源完成一次可核验的研究简报写回，让研究问题、证据、不同观点、未知点、来源和关联笔记形成稳定的自动化契约。

**Blocked by:** 03 待查候选与研究任务生命周期

**Status:** done

- [x] 来自日记或想法的研究任务生成一份位于顶层研究目录下一层的简报，不创建嵌套目录或静默覆盖无关旧文件。
- [x] 简报包含研究问题、结论摘要、事实与证据、推断、建议、多视角与反方审查、未知点、限制、研究方法和来源信息。
- [x] 假来源 adapter 能提供原始资料、独立确认、冲突证据和反方资料；测试不依赖真实网络或模型措辞。
- [x] 每个关键结论都能关联到实际来源标题、作者或机构、日期、访问日期、完整 URL、适用范围和限制；无法核验的内容标为未知。
- [x] 简报与来源日记或想法双向互链；同一来源与问题的更新复用已有简报并记录证据差异。
- [x] 只有简报和双链写回验收通过时才将状态设为 `complete` 并关闭 `needs_research`；证据不足或 runner 失败时保留 `partial` 或 `blocked` 与 `needs_research: true`。
- [x] 三大项视频分析样例区分可观察动作异常、技术可行性和医学诊断边界，并记录个人验证路线、变量和指标。
