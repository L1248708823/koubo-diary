# 01 — 处理 prompt 单一来源与 Yan帳 语义落地

**What to build:** 让一次完整的收件项处理使用统一的 Yan帳 内容整理契约，模型能稳定区分日记、想法、待查和研究任务，运行时 prompt 不再声称包含实际未提供的完整规则。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 用户可见的产品主题使用 Yan帳，原始输入使用收件项或原始记录等精确内部概念。
- [ ] 运行时 prompt 与指定处理 skill 使用同一份语义规则，不存在摘要覆盖完整规则的情况。
- [ ] 日记保留日期、过程、现场语境和个人声音，想法脱离当天背景仍可理解。
- [ ] 想法轴与待查轴可以独立组合，研究任务不会被误当成想法或研究简报。
- [ ] 混合收件项中的事实、情绪、判断和待查问题不会被合并成单一结论。
- [ ] 处理结果仍通过现有回执、路径和收件项所有权验收。
- [ ] 保留人工内容审查样例，覆盖长期目标、当天计划、相似想法和研究后续想法。
