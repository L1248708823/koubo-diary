# 01 处理轮次安全契约

**What to build:** 处理端能够以唯一轮次身份消费一批收件项，并在任何回执或工作区越权时保留原文、恢复可恢复的危险变更。只有机械验收通过的 `done` 项才会被脚本清理。

**Blocked by:** None，可立即开始

**Status:** done

- [x] 每轮生成唯一 `round_id`，并同时传给 agent、写入回执；缺失、过期或不匹配的回执不能通过验收。
- [x] 当前快照内每条收件项在回执中恰好出现一次，拒绝漏报、重复、快照外条目和旧回执复用。
- [x] agent 修改、移动、重命名或删除收件箱文件时整轮失败；原始收件项保留，并尽可能恢复危险的新增、修改和路径变更。
- [x] 嵌套 `Yan帳`、长期目录子目录和其他白名单外变更会被拒绝并清理，合法日记、想法、研究和处理状态写回仍可通过。
- [x] 回执声明的日记、想法和研究文件都必须真实存在且路径合法；验收通过前不删除收件箱。
- [x] 自动化测试使用临时 vault 和假 agent 覆盖上述成功、失败、恢复及 attempts 隔离行为。
