# 日记写回既有按日树，想法顶层扁平且 v1 不归档

个人 vault 已有按日回顾习惯（`生活/日子一天天过去/年/月/日`），另建平行「口播日记」区会增加打开心智负担。想法则要可脱离「今天」单独检索、双链，且 v1 量级下不值得上按年目录或自动归档。

决定：

1. **日记**：成功处理的口播写回  
   `生活/日子一天天过去/YYYY/YYYY-MM/YYYY-MM-DD.md`  
   同一天合并进同一篇；新建月目录用规范名 `YYYY-MM`（无前导空格）；不写入 `吾志/`、`wolai-app/` 等旁支。
2. **想法**：顶层扁平 `想法/短标题.md`，**一条想法一个文件**；不按日/月大杂烩；标题冲突则改名新建，不自动合并进旧文件。
3. **互链**：日记侧为时间戳 + 一句钩子 + `[[想法/…]]`；想法侧为轻整理全文 + 链回当日日记；避免双份全文（延续 ADR-0005）。
4. **双轴语义（模型判，捕捉端不选手动分类）**  
   - 想法轴：能否离开「今天」单独回看 → 是否建想法文件（宁可少抽）  
   - 待查轴：是否有未决认知缺口 → 只标记，v1 不调研、不编结论（宁可少标）  
   - 两轴可组合，非互斥。
5. **归档**：v1 不对想法做按年目录或到期自动搬迁；时间靠 frontmatter / 源日记链接。库膨胀后再议 `_archive` 或 status。

配置上 `DIARY_DIR` 取日记树前缀（默认示例即上述路径），`IDEAS_DIR=想法`；白名单放行日记树子路径，但想法只放行 `IDEAS_DIR/文件名.md` 这一层。

## Considered Options

- 新建扁平 `日记/` 与历史树并存（实现更简单，增加切换负担，未采纳为 v1 主路径）
- 想法按年/月分桶或按日杂烩（削弱「离开今天」的实体感，未采纳）
- v1 即自动按年归档（链接与路径成本高、想法宜常青，推迟）
- 开放自由 tag 分类（易大杂烩；v1 仅保留待查等领域标记）
