# 01：收件项到日记与想法关联

**What to build:** 把一条或多条收件项稳定地处理成当日日记和长期想法。日记只做轻度整理，想法根据内容判断创建或关联，明确延续时更新已有想法。主处理端使用明确的模型参数，并且只读取允许关联判断的顶层想法和研究内容。

**Blocked by:** None, can start immediately.

**Status:** ready-for-agent

- [ ] 每条验收成功的收件项都写入对应日期的日记，同一天多条内容按 `captured_at` 排序，每条保持独立段落。
- [ ] 日记只处理错别字、标点、断句和排版，保留情绪、语气、犹豫、强调、重复和未决问题。
- [ ] 收件项验收后继续按现有流程清理，不新增原文副本或原文归档。
- [ ] 想法判定不依赖 `我想`、`我发现` 等关键词，只有形成明确、可脱离当天回看的命题时才创建想法。
- [ ] 想法文件使用收件项捕捉日期命名，保留完整捕捉时间和来源日记关联。
- [ ] 一条收件项中多个独立命题可以分别创建想法，拆开后需要补充上下文时保持原内容结构。
- [ ] 新内容明确延续已有想法时更新已有文件、保留旧正文并追加新的日记关联，关系不清楚时不自动合并。
- [ ] 内容整理 agent 可以读取顶层想法和研究内容用于关联判断，但不能扫描整个 vault 或读取无关目录。
- [ ] 主处理端调用显式使用模型 `gpt-5.6-luna` 和思考程度 `max`。
- [ ] 现有收件箱所有权、回执和路径验收契约继续通过。
