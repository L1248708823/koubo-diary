# 先完成日记写回，再分别处理想法和研究

Status: accepted

上线首轮表明，日记和想法可以成功写回并发布，即使研究 runner 未能产出合法的研究简报。由此决定：处理端先保证收件项对应的日记可靠写回；想法写回、研究任务和研究简报分别记录自己的状态，某一项失败时不能丢失或否定已经成功写回的日记。日记只做错别字、标点、断句和排版等轻度整理；只有确定删除后不影响意思、情绪和语气时，才删除重复或停顿词，拿不准就保留。同一个词连续出现后马上改口或纠正的重复可以删除，为了表达情绪或强调而重复的内容必须保留。同一天的多条收件项合并到同一篇日记，每条收件项单独成段并按捕捉时间排序，整理不跨收件项进行。想法只有在内容明确表达使用者的观点、假设、创意或方法，脱离日记仍能理解且值得回看，并且不需要处理端补背景、理由或结论时才创建；固定句式只作提示，只有问题时标待查，模糊念头先留在日记里。一条收件项里有多个互不相关且各自能看懂的想法时分别创建文件，拆开后需要补上下文时不拆。收件项验收完成后按原流程清理，不另外保存收件项原文。研究任务的自动触发策略后续单独讨论。
