# 写回以日记为轴，并可抽出想法笔记

原始记录处理后的信息要按日可回顾，又要让独立灵感可检索、可双链。决定：每条成功处理至少更新当日日记（来自 `captured_at` 的时间戳 + 轻整理短段）；模型判定为独立想法时另建想法笔记并与日记互链；避免日记与想法双份全文（日记侧以短段或链接为主，想法侧保留全文）。存在认知缺口时登记研究任务，由独立研究 runner 处理；研究失败或证据不足时保留 `needs_research: true`，不写无来源确定性结论。

## Considered Options

- 严格单落点（日记或想法二选一）
- 全部只进日记、想法仅标签
- 日记为轴 + 可选想法笔记（采纳）
