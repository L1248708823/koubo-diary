# 01 — 处理环异常显式失败

**What to build:** 当收件箱、工作区、Git、状态文件或恢复动作发生真正错误时，让当前处理轮明确失败并保留可诊断原因；预期的首次缺失、锁竞争和幂等清理继续保持原有行为。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 收件箱读取权限错误不会被当成空收件箱。
- [ ] 收件项读取或失败次数读取错误不会重置重试计数。
- [ ] 本地工作区快照和真实 Git 状态读取失败会阻止验收和发布。
- [ ] Git 恢复命令失败不会被当成文件不存在，也不会因此删除不应删除的文件。
- [ ] 越权变更恢复失败、状态写回失败和失败路径发布失败会进入处理轮结果或明确日志。
- [ ] 仅明确允许的缺失文件、锁竞争和幂等清理可以返回空值或已处理结果。
- [ ] 正常收件、失败计数、隔离和锁占用行为保持可运行。
