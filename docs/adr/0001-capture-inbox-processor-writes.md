# 捕捉端只写收件箱，处理端独占正文写入

个人工具跑在已有 Obsidian vault 和 Git remote 之上。若捕捉端（通常在手机）直接改当日日记或想法正文，会与处理端或 PC 侧同步抢同一文件，合并冲突风险很高。

决定：捕捉端只能向同一日记仓的收件箱**新建**文件；日记合并、想法落盘、收件箱清理只由处理端执行。处理端的生产宿主固定为 VPS，具体 Git 生命周期见 ADR-0003 和 ADR-0004。

## Considered Options

- 捕捉端直接写正文（Git 或 GitHub API）
- 捕捉只投递、处理端写正文（采纳）
- 第一版仅 PC 端、放弃移动捕捉
