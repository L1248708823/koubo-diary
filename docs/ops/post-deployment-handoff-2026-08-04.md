## 2. 已发现并解决的问题

### Git 中文路径验收失败

第一次真实处理时，日记和想法实际已经写入，但 Git 默认把中文路径输出成八进制转义，程序误以为路径不在白名单内，导致验收失败。

处理方式：

- Git 状态读取增加 `core.quotePath=false`。
- 自动化测试和类型检查通过。
- 修复已提交并推送到工具仓。
- 修复后重新处理成功，日记、想法、收件箱删除和 Git 推送均正常。

### 研究阶段阻塞

## 3. 已确认的产品方向

### 只保留三个概念

当前范围只保留：

1. 日记
2. 想法
3. 调研

暂时不增加行动、项目、任务等概念。

### 日记：完整内容的轻整理

日记不是摘要，也不是 AI 总结。

允许：

- 纠正明显错别字。
- 调整标点、断句和排版。
- 删除无意义的口头填充。
- 合并明显重复。
- 保留原有语气、情绪词、犹豫和不确定表达。

不允许：

- 把完整口播压缩成一句话。
- 删除“终于、卧槽、担心、我在想”等有意义的表达。
- 替用户推断未说出的情绪。
- 把问题改写成结论。
- 因为内容被判定为想法，就从日记中移除原文。

处理顺序应为：

```text
收件 → 先完整轻整理并写入日记 → 再判断想法 → 再判断调研
```

### 想法：长期命题卡

想法不是日记全文副本，而是脱离当天语境后仍值得回看的个人命题、假设、创意或观点。

想法可以包含：

- 核心命题。
- 我为什么在意。
- 当前假设。
- 可能的反例。
- 来源日记。
- 当前状态。
- 是否需要调研。

想法可以和调研同时出现，但二者不重复：

- 想法记录“我提出了什么”。
- 调研回答“外部事实和证据是什么”。

### 想法需要日期

已确认：想法必须带来源时间。

推荐格式：

```yaml
created_at: 2026-08-04T15:16:18+08:00
source_captured_at: 2026-08-04T15:16:18+08:00
source_diary: 生活/日子一天天过去/2026/2026-08/2026-08-04.md
```

暂定不把日期放入文件名，以避免标题变化导致链接失效；是否同时显示在标题中，待本地设计时决定。

## 4. 调研方向（仍在讨论）

当前调研是两阶段：

```text
普通 Codex：登记研究任务，不联网
research runner：独立调研并写研究简报
```

当前问题是研究契约可能过度限制了分析方式。方向上建议：

- 允许 AI 自行拆解问题。
- 允许 AI 判断需要事实检索、方案比较、架构分析或反方论证。
- 允许 AI 给出推荐，但必须区分事实、推测和建议。
- 必须说明证据、来源和不确定性。
- 允许 AI 判断某个问题其实不值得调研。
- 继续限制文件范围、密钥访问、外部副作用、调用时间和成本。

核心原则：

> 限制 AI 的权限，不限制 AI 的思考。

推荐采用“自主分析 + 硬边界”，但尚未最终决策。

## 5. 待本地决策的问题

### 日记

- 是否只保存轻整理后的完整文本，还是额外保存一份完全原始口播。
- “轻整理”是否允许删除无意义重复，删除到什么程度。
- 是否需要给每条日记保留 `source_id`，方便追溯原收件项。

### 想法

- 日期只放 frontmatter，还是同时显示在标题。
- 想法状态使用哪些值：`seed`、`researching`、`validated`、`rejected`、`implemented` 等。
- 想法是否必须包含独立命题，还是允许“值得继续观察的模糊念头”。

### 调研

- 是否允许直接给出推荐方案。
- 不同主题是否使用不同调研模式：事实、技术比较、产品分析、架构设计等。
- 来源要求是所有事实都必须有来源，还是只对外部可验证事实要求来源。
- 调研失败时，是否只标记调研阻塞，而不让整个 processor 退出失败。
- 调研简报是否需要反向更新想法状态。

## 6. 本地接手建议

本地修改优先，服务器只负责运行已审核版本。

建议顺序：

1. 本地拉取工具仓最新 `main`。
2. 根据本文修改 skill、提示词、类型和验收测试。
3. 先运行测试、类型检查和构建。
4. 本地使用临时 vault 做端到端测试。
5. 提交并推送工具仓。
6. VPS 再执行 `git pull --rebase`，审核后重启服务。

不要从服务器复制以下内容到本地仓库：

- `/etc/koubo/koubo.env`。
- 真实 token。
- `/run/koubo` 下的锁文件。
- 真实日记仓全部内容，除非明确需要查看某条样例。

## 7. 下一阶段验收标准

- 日记保留原口播的主要信息、情绪和说话方式。
- 日记只做编辑，不做内容摘要。
- 想法不再是日记全文复制品。
- 想法带有日期和来源日记。
- 想法和调研可以同时存在，并且相互链接。
- 调研可以分析、比较和推荐，但必须标注证据与不确定性。
- 调研阻塞不会掩盖已经成功的日记写回。
- 中文路径、想法、研究简报和 Git 发布全部通过自动化测试与真实烟测。
